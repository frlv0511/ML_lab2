## Что сделано

**Часть 1 (датасет `data/Lab2_Dataset_PCA.xlsx`, признаки a–e; y — только для раскраски графиков):**
1.1 матрица корреляций; 1.2 матрица разброса; 1.3 значимость признаков и шум методами PCA, SVD, ICA;
1.4 главные / второстепенные / шумовые компоненты и графики значимости; 1.5 проекции на две главные компоненты со стрелками признаков.

**Часть 2 (датасет `data/Lab2_Dataset_Clustering.xlsx`, признаки a, b):**
12 алгоритмов кластеризации sklearn; 2.1 применимость; 2.2 общий график результатов; 2.3 подбор параметров;
2.4 выделение аномалий (DBSCAN, HDBSCAN, OPTICS); 2.5 сравнение с эталоном y.

## Запуск

```
pip install -r requirements.txt
python main.py
```

Все рисунки (`.png`), таблицы (`.csv`) и журнал консоли (`run_log_*.txt`) сохраняются в папку `output/`.

```
main.py                 # точка входа: задания 1.1–1.5, 2.1–2.5
```
